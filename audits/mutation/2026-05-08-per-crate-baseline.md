## Methodology

- cargo-mutants version: **25.3.1** (per workspace pin in
  `.cargo/mutants.toml` header).
- Per-crate invocation pattern:
  ```sh
  cargo mutants \
    --config audits/mutation/per-crate-configs/<crate>.toml \
    -p <crate> --in-place --baseline=skip \
    --output audits/evidence/mutants/<crate>
  ```
- **Test scope**: per-crate, scoped via the override config in
  `audits/mutation/per-crate-configs/<crate>.toml` to avoid the
  pre-existing `chio-acp-proxy` failing test on main. The test scope
  is empirically verified by reading
  `audits/evidence/mutants/<crate>/mutants.out/debug.log`. See PR #619
  (chio-attest-verify) for the original methodology rationale.
- `--baseline=skip` is used because the per-package test suite is
  known green at HEAD; skipping the baseline run avoids redundant
  re-verification per crate.
- `--in-place` is used (instead of cargo-mutants' default copy-tree
  mode) to avoid `target/` duplication on a 50+ crate workspace.
- `--output` writes a per-crate `mutants.out/` directory under
  `audits/evidence/mutants/<crate>/`.

## Target satisfaction note

A "target met" claim requires either a full per-crate run OR a
pre-registered statistically defensible sampling scheme.

- `chio-weights` (68.3%) is measured on a FULL 66/66 mutant run
  (cargo-mutants exit 2; expected for runs with surviving mutants).
  The examine_globs surface covers all four logic-bearing source
  files (`bundle.rs`, `card.rs`, `error.rs`, `lineage.rs`), avoiding
  the chio-guards (PR #621) hand-picked-subset anti-pattern. **The
  >=65% target is met.**
- The 20 missed mutants cluster in two test-quality gaps:
  - `card.rs` `StringSet` pure-getter methods have no dedicated unit
    tests asserting their exact returned values (11 mutants).
  - `card.rs` `<` -> `<=` boundary conditions in
    `ModelCard::require_live` and `ModelCard::validate` lack
    exact-equal-timestamp test fixtures (2 mutants).
  - `lineage.rs` `anchor_projection_bytes` and `sha256_hex` are
    round-trip-pinned (called on both sides) and need golden-bytes /
    RFC 6234 vector fixtures (5 mutants).
  - 1 `verify_model_card_anchor` negation-delete mutant on a
    defensive `!is_lowercase_hex_signature_payload` check.
  See `audits/evidence/mutants/chio-weights/2026-05-08.json`
  `missed_mutant_categories` and the README in that directory.

Kill rate is computed as `caught / (caught + missed + timeout)`,
**excluding** unviable mutants from the denominator per cargo-mutants
25.x convention.
