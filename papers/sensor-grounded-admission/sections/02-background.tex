\section{Background}
\label{sec:background}

\paragraph{Polity admission.}
A polity is a triple $(T, C, K)$: a closed receipt-admission scope $T$, a Merkle-rooted citizenship roster $C$, and a constitution $K$ given as a finite list of predicates. Admission of a receipt $r$ is the decidable Boolean
\[
  \mathsf{polityAdmits}(P, r) = T(r) \wedge \mathsf{allPredicates}(K, r).
\]
A bilateral treaty admits $r$ iff treaty scope, treaty constitution, and both polities' admission relations accept~\thm{treaty_admission_iff_predicate_intersection}. The trust ladder has five ordered modes (observation, guarded, receipt-backed, partition-contingency, quorum-required), and treaty admission is stable under any mode at or above the treaty's mode floor~\thm{treaty_admission_stable_under_ladder_floor}. The parent paper fixes the wire format: signed Ed25519 over canonical-JSON~\cite{rfc8785}, DSSE envelopes binding bodies via subject digest~\cite{dsse}, fail-closed on malformed envelopes and predicate-type mismatches.

\paragraph{The honest-substrate assumption.}
The parent construction is sound up to one limitation it names: the verifier-owned trust stores and the signing kernel are honest with respect to their own substrate state. A kernel that has lost a sensor at decision time can still produce a body that parses cleanly and signs cleanly. The bilateral predicate confirms that two kernels signed the same body and agreed on the same canonical bytes; it cannot distinguish two kernels that signed under complete observation from two kernels that signed under partial observation. The honest-substrate assumption is therefore not a separate cryptographic layer but a stipulation that runs through the entire admission predicate, occupying the position that the Coker principle of \emph{trustworthy mechanism} holds in the formal-models-of-attestation literature~\cite{cokerPrinciplesRemoteAttestation2011}.

\paragraph{Sensor state on real kernels.}
Real admission kernels are composed of multiple sensors: kernel callouts, network-flow verdicts, code-signature drift detectors, supply-chain runtime guards, behavioral telemetry. Each reports installed, active, healthy, degraded, and event-dropped state at runtime, and a kernel produces receipts using whichever are live at decision time. The receipts inherit, implicitly, the posture of the sensors that contributed to them. The kernel knows which sensors were live; the verifier does not. Lifting that knowledge into a signed attestation that travels with the receipt closes the gap structurally.

\paragraph{OS-level referents.}
The sensor categories have direct referents in production endpoint stacks. On Linux, the audit subsystem and the Integrity Measurement Architecture supply kernel callouts and code-signature evidence~\cite{linuxAuditSubsystem,sailerTCGIMA2004}. On macOS, the Endpoint Security framework exposes a typed event stream covering process, file, and signing-identity activity~\cite{applePlatformSecurity2024}. On Windows, Event Tracing for Windows is the analogous high-volume provider channel that endpoint products consume~\cite{microsoftETW}. The construction in this paper sits at the admission layer above these provider channels rather than at the endpoint-detection product layer.

\paragraph{Property attestation as the lineage.}
The sensor-state attestation introduced in Section~\ref{sec:substrate} joins a tradition. Load-time integrity measurement on a TCG root attests which code is running~\cite{sailerTCGIMA2004}; semantic remote attestation lifts the attested object from \emph{which code} to \emph{which property of the code}~\cite{haldarSemanticRemoteAttestation2004}; the principles-of-remote-attestation program formalizes what an attestation must carry to be useful~\cite{cokerPrinciplesRemoteAttestation2011}. Trusted-execution-environment platforms (Intel TDX, AMD SEV-SNP, AWS Nitro, ARM CCA, NVIDIA Hopper Confidential Compute, Microsoft Azure Attestation)~\cite{chengTDXDemystified2024,amdSEVSNP2020,hammoudConfidentialCloud2023,msaa2025} attest at a different layer: launch measurements rather than per-receipt sensing state. A TEE-rooted kernel that attests degraded sensing is structurally degraded under the admission predicate even if its TEE attestation is healthy. Section~\ref{sec:related} returns to this lineage in depth.
