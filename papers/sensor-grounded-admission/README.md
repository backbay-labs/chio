# Sensor-Grounded Admission

LaTeX project for `Sensor-Grounded Admission: Polity Receipts with Attested Substrate State`. The paper conditions receipt admission on a signed attestation of the kernel's sensing posture at decision time: the attestation lists each registered sensor's health flags and drop counts, is canonicalized into the same DSSE subject digest as the receipt body, and the admission predicate succeeds only when the required sensor set is attested healthy. The headline result is an existence-of-witnesses theorem showing that two receipts with identical body bytes but distinct attestations discharge the admission predicate to opposite verdicts; three supporting theorems connect the structural distinction to the parent paper's five-mode ladder and to the destructive-admission floor. Build with `make build-usenix` (or `make build-acmart` for the ACM format variant) from this directory. Text is intended for CC-BY-4.0 review circulation.
