Launch the pinned Hermes CLI with only the Chio execution gateway. This
candidate mode uses static host tool restrictions, independent of the legacy
Python plugin's hook. Resource isolation and the kernel gateway remain
separate required boundaries. The qualified mode adds a default-deny macOS
profile and an operator-owned model relay.
