# Chio Wire Schemas v1: receipt/

This subtree contains the machine-readable JSON Schema (draft 2020-12) contract for receipt primitives that anchor `spec/PROTOCOL.md`. `record.schema.json` describes a signed receipt envelope, `inclusion-proof.schema.json` describes Merkle membership, `lineage_statement.schema.json` binds receipt lineage, `admission-metadata.schema.json` defines the durable admission projection embedded under `metadata.admission_operation`, `delivery-contract.schema.json` defines the output-digest delivery evidence embedded under `metadata.delivery_contract`, and `finding-delivery.schema.json` defines the purchased-finding delivery overlay embedded under `metadata.finding_delivery`.
