# Chio Wire Schemas v1: trust-control/

This subtree contains the machine-readable JSON Schema (draft 2020-12) contract for the four trust-control plane primitives that anchor `spec/PROTOCOL.md` section 9 ("Trust-Control Contract"). The four schemas form the lifecycle envelope of one operator-visible authority lease: `lease.schema.json` describes a single authority lease projection (mirroring the cluster authority lease view in `crates/platform/chio-control-plane`); `heartbeat.schema.json` describes a lease refresh request that targets that lease; `terminate.schema.json` describes a voluntary lease release request; and `attestation.schema.json` describes one normalized runtime attestation evidence statement carried alongside trust-control authority operations and governed capability issuance (mirroring `RuntimeAttestationEvidence` in `crates/core/chio-core-types`, populated by the verifier bridges in `crates/platform/chio-control-plane`). Wire field names are camelCase across the family so the lease projection, heartbeat, and termination requests stay consistent on the wire.
