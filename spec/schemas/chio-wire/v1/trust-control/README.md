# Chio Wire Schemas v1: trust-control/

This subtree contains the machine-readable JSON Schema (draft 2020-12) contracts that anchor `spec/PROTOCOL.md` section 9 ("Trust-Control Contract"). The lease lifecycle uses `lease.schema.json`, `heartbeat.schema.json`, and `terminate.schema.json`; `attestation.schema.json` describes normalized runtime attestation evidence. `budget-snapshot-anchor-provenance.schema.json` defines the leader-signed inclusion chain that allows a fresh follower to authenticate immutable pre-upgrade budget usage anchors without weakening the ordinary snapshot import anti-forgery rule. Wire field names are camelCase across the lease and budget provenance families.
