# Chio Wire Schemas v1: provenance/

This subtree contains the machine-readable JSON Schema (draft 2020-12) contract for the four provenance-graph primitives that anchor `spec/PROTOCOL.md` provenance prose and the tool-call fabric: `stamp.schema.json` is the wire form of the provenance stamp (canonical fields `provider`, `request_id`, `api_version`, `principal`, `received_at`); `context.schema.json` mirrors the `GovernedCallChainContext` struct in `crates/core/chio-core-types`; `attestation-bundle.schema.json` carries an ordered list of normalized runtime attestation evidence statements that mirror `RuntimeAttestationEvidence` in `crates/core/chio-core-types` and bind them to a governed `chainId`; `verdict-link.schema.json` binds a Chio policy verdict (vocabulary aligned with `spec/schemas/chio-http/v1/verdict.schema.json`) back to the provenance graph via `requestId`, optional `receiptId`, and `chainId`. Field-name casing follows the closest live Rust shape: `stamp` uses snake_case to match the `RuntimeAttestationEvidence` provenance-adjacent shape; `context`, `attestation-bundle`, and `verdict-link` use camelCase to match the `GovernedCallChainContext` family they bind to.
