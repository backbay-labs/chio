# T1.1 - Macaroon capability attenuation

**Status**: pending. **Owner**: TBD (capability eng lead).

**Tickets**: TRJ4-110 through TRJ4-118, plus `TRJ4-T1.1.E` Evidence Gate.

## Scope

The 4-way consensus keystone. Promote existing `delegation_v2` primitives to default-on, lift `Attenuation`/`ScopeAttenuation` into the negotiated `chio.capability.v2` schema as first-class wire fields, and ship new witness-generation/verification APIs.

**Critical correction (round-5)**: today's `validate_attenuation(parent, child)` only checks `child.is_subset_of(parent)` and returns `Ok(())` or `Err`. It does **not** produce a witness. T1.1 ships a new API pair alongside it; the `attenuation_proof` field carries the witness on the wire.

## Acceptance

1. **Promote `delegation_v2` to default-on** (TRJ4-110): feature gate removed; `cargo --workspace --no-default-features` build verified to still link.
2. **Lift `Attenuation` and `ScopeAttenuation` as first-class v2 fields** (TRJ4-111): `chio.capability.v2` schema and Rust struct both expose them outside the `delegation_v2` cfg.
3. **Typed caveats** (TRJ4-112): `Vec<Caveat>` reachable from `ToolGrant`; each `Caveat { kind, predicate, sig? }`. Implementation in `chio-policy/src/capability.rs`.
   - First-party caveat kinds: `restrict_tool`, `bind_session`, `restrict_audience`, `restrict_geo`, `restrict_time_window`.
   - Third-party caveats with discharge are an XL follow-on; not in T1.1 scope.
4. **NEW API: `compute_attenuation_witness`** (TRJ4-113):
   ```rust
   pub fn compute_attenuation_witness(
       parent: &ChioScope,
       child: &ChioScope,
   ) -> Result<AttenuationWitness>;
   ```
   `AttenuationWitness` records normalized canonical encoding of each scope, per-grant subset relation, and any restricted predicates.
5. **NEW API: `verify_attenuation_witness`** (TRJ4-114):
   ```rust
   pub fn verify_attenuation_witness(
       parent_hash: &ScopeHash,
       child_hash: &ScopeHash,
       witness: &AttenuationWitness,
   ) -> Result<()>;
   ```
   Faster than re-deriving subset normalization; verifier path uses this when the witness is on the wire.
6. **`attenuation_proof` field** on `chio.capability.v2` carries the witness (TRJ4-115). `parent_scope_hash`, `child_scope_hash`, `normalized_subset_proof` fields populated.
7. **`CapabilityAttenuationGuard`** (TRJ4-116): runtime guard that runs `validate_attenuation` AND `verify_attenuation_witness` on every cap presentation; both must pass.
8. **`chio-federation::delegation::issue_token` / `verify_chain`** (TRJ4-117): cross-org scoped delegation token. Short-lived bearer (default TTL 4h), action-scoped, revocable. Carries `delegator_did, delegate_did, scope_namespace, allowed_actions, expires_at, parent_token_hash, max_remaining_hops`. Delegate kernel attaches the token to receipts so any verifier can re-derive the chain.
9. **`SubAgentBudgetPropagation`** (TRJ4-118): `BudgetSplit` carried in child receipts and verified at join. **Fixed-point integer share field** (basis points or micros); no floats inside signed/canonical authority artifacts.

## Evidence Gate (TRJ4-T1.1.E)

Closes only when:

- `spec/PROTOCOL.md` updated with the typed-caveat language, `attenuation_proof` field semantics, and the new witness API contract.
- `spec/schemas/chio-wire/v1/capability/token.v2.schema.json` (or equivalent) lifts `Attenuation`/`ScopeAttenuation` and adds `attenuation_proof`, `caveats`.
- Claim registry: `chio.capability.v2 attenuation_proof` claim registered.
- Proof manifest: tied to `verify_attenuation_witness` Lean theorem.
- Theorem inventory: `compute_attenuation_witness` correctness and `verify_attenuation_witness` soundness theorems registered.
- Generated proof report regenerated and committed.
- Negative conformance tests:
  - Forged `attenuation_proof` (correct shape, wrong hashes) fails closed.
  - Replayed witness with stale `parent_scope_hash` fails closed.
  - Caveat `restrict_tool` with non-subset value fails closed.
  - Sub-agent budget that re-amplifies parent (share > 1.0 expressed as bps > 10000) fails closed.

## Evidence to capture

- Round-trip test: parent token -> attenuated child token -> verify chain -> receipt carries `attenuation_proof`.
- Cross-org delegation interop: tenant A issues delegation to tenant B; B's receipts verify back to A's trust anchor.
- Budget-split conformance: parent budget = 10000 bps; three children at 3000 + 3000 + 3000 OK; one child at 12000 fails.
- Lean theorem proof report.

## Risks / open questions

- `compute_attenuation_witness` performance on pathological scope shapes (1000+ grants); benchmark before claiming the witness API is faster than re-derivation.
- `delegation_v2` may have per-call-site assumptions that the feature is off; audit and fix.
- Third-party caveats with discharge are deferred to trj5+; document as a known limitation in PROTOCOL.md so adopters aren't surprised.
