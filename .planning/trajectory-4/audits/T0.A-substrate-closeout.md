## Release-tag policy (ratified before TRJ4-002)

The plan and prior trj3 closeout posture used the placeholder `v3.18.1-trj3.1`. Ground-truth check at ratification time shows the existing release tags are:

```
cpp/v0.1.0
v0.0.0-m03-probe
v0.1.0
v2.0
```

`v3.18.1` is still a multi-major-version jump with limited precedent. The policy is ratified as option 3 for trj4 because `SYNTHESIS-V2-INTEGRATED-PLAN.md` close-bar item 9 explicitly names `v3.18.1-trj3.1`, and changing the tag family during execution would desynchronize the close bar, release artifact paths, and audit evidence.

Ratified policy:

- Adopt `v3.18.1-trj3.1` for the trajectory-3.1 close anchor.
- Accept the version discontinuity for this internal trajectory closeout.
- Do not backfill historical `v0.2..v3.17` tags.
- Record the canonical tag, SHA, and release workflow URLs in `releases.toml`.
