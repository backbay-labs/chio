# T1.4 - Archaeology finish-line

**Status**: pending. **Owner**: TBD (refactor + supply-chain eng lead).

**Tickets**: TRJ4-150 through TRJ4-160.

## Scope

Two highest-leverage codebase debt items from the archaeology brainstorm: extract the cookie-cutter provider-adapter pattern into a shared crate, and fix `chio-hosted-mcp`'s `#[path]`-splice public surface. Plus the cargo-vet exemption burn-down.

## Acceptance

1. **`chio-hosted-mcp` real extraction** (TRJ4-150):
   - Lift `remote_mcp/*.rs` from `chio-cli` into a new `crates/chio-mcp-remote/` (or equivalent name) crate.
   - Both `chio-cli` and `chio-hosted-mcp` consume it as a normal dependency.
   - `chio-hosted-mcp/src/lib.rs` no longer contains `#[path = "../../chio-cli/src/remote_mcp.rs"]` directives.
   - Workspace public-entrypoint metadata updated.
2. **`chio-provider-adapter-core` extraction** (TRJ4-151):
   - New `crates/chio-provider-adapter-core/` workspace member.
   - Shared SSE-gate orchestration (extracts the `gate_sse_stream` shape from the seven existing adapters).
   - Shared `LoadedWeights` impl helper (replaces 5x near-clone `loaded_weights.rs` files).
   - Shared `Provider` trait that captures the 80% common surface.
3. **Refactor 7 provider adapters** to consume `chio-provider-adapter-core` (TRJ4-152..158):
   - `chio-cohere-tools-adapter`
   - `chio-mistral-tools-adapter`
   - `chio-groq-tools-adapter`
   - `chio-ollama-tools-adapter`
   - `chio-gemini-tools-adapter`
   - `chio-anthropic-tools-adapter`
   - `chio-bedrock-converse-adapter`
   - Each adapter shrinks to ~200 LOC after refactor (target: total LOC across the seven shrinks by ~3 KLOC).
   - Provider-specific frame parsing remains in the adapter; orchestration moves to core.
4. **Cargo-vet "no net-new exemptions" CI gate** (TRJ4-159):
   - Workflow check on `supply-chain/config.toml` blocks any PR that increases the `[[exemptions.*]]` count.
   - Manual override requires a justification comment in the PR.
5. **Top-50 dependency real audits** (TRJ4-160):
   - Author cargo-vet audit entries for the 50 highest-traffic dependencies (`alloy-*`, `aws-sdk-*`, `tokio-*`, `hyper-*`, `tonic-*`).
   - Target: 819 -> <= 769 exemptions (50 burn-down).
   - Each authored audit lives in `supply-chain/audits.toml` with a `criteria = "safe-to-deploy"` line and a one-paragraph justification.

## Risks / open questions

- The `Provider` trait may not capture every adapter's quirks (e.g., Bedrock's IAM-principal flow, Anthropic's tool-use schema). Allow per-adapter trait methods to override.
- Cargo-vet audits for `aws-sdk-*` are hundreds of crates each; document audit-by-version-range strategy and ship the first 50 high-leverage ones rather than all.
- `chio-hosted-mcp` rename of internal modules may break downstream consumers; coordinate with M10 stakeholders even though M10 is external.
