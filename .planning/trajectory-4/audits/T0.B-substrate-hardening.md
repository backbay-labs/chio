## Lane A slice evidence

First substrate-hardening slice covers the cheap high-value TRJ4-021, TRJ4-022,
and TRJ4-023 work without touching mobile verifier scope:

- TRJ4-021: `chio-tee-frame` now exposes `validate_signed` and
  `verify_tenant_sig`, verifying `tenant_sig` as an Ed25519 signature over the
  canonical frame body with `tenant_sig` removed. Existing no-key `validate`
  remains structural; callers with a tenant key can now fail closed in the
  frame crate instead of duplicating verifier logic.
- TRJ4-022: `schema::validate_timestamp` still enforces the exact
  `YYYY-MM-DDTHH:MM:SS.mmmZ` wire shape and now parses the value with an
  RFC3339 parser, rejecting impossible dates and times.
- TRJ4-023: `chio-http-core::HttpEgressContract` declares tenant namespace,
  allowed schemes, exact authorities, loopback and link-local denials, IPv6
  ULA denial, redirect ceiling, and response-byte ceiling. Missing contracts
  fail closed via `HttpEgressContract::enforce_required(None, ...)`.

Focused validation:

- `cargo test -p chio-tee-frame` passed: 21 unit tests, 2 property tests, 0 doc
  tests.
- `cargo test -p chio-http-core --test http_egress_contract` passed: 9 tests.
- `cargo check -p chio-http-core -p chio-tee-frame -p chio-conformance`
  passed.
- `cargo clippy -p chio-http-core -p chio-tee-frame -p chio-conformance --tests -- -D warnings`
  passed.
