# Chio 7.5 Shadow

The 7.5 shadow target is production runtime operations hardening after local
runtime orchestration is proven.

Candidate scope:

- long-running local runtime operator supervision
- orchestration report retention and status aggregation
- explicit operator recovery drills for stuck local runs
- richer provider health checks for static local provider bindings
- keep dynamic trust, peer discovery, settlement execution, hidden predicates,
  VC Data Integrity BBS, zkVM, FROST, new transports, pheromone-driven
  authority decisions, and live notification dispatch deferred unless
  explicitly promoted
