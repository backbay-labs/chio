# Support runbook

Ask the customer for the operation ID and the observed error. Do not ask for signing keys, model credentials, or an unredacted customer database.

For a missing report response, check the report status using its operation ID. If the status is unresolved, escalate to the effect owner instead of asking the customer to retry publication.

Support case summaries are retained for 30 days under policy SUP-04. This is a different record class from engineering incident artifacts.
