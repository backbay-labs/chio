# Chio Release Checksum Indexes

This directory contains public checksum indexes for Chio release artifacts.
Each `v<tag>.txt` file is generated by `.github/workflows/release-binaries.yml`
after the release matrix publishes GitHub Release assets.

## Format

Each checksum index is ASCII text:

```text
# chio checksum index v1.2.3
# source_ref refs/tags/v1.2.3
# source_sha <40-character git sha>
# slsa_provenance chio-<source_sha>.intoto.jsonl
# rekor_witness search https://search.sigstore.dev for the SLSA intoto payload after slsa.yml publishes provenance
# rekor_tlog_scope SLSA provenance plus checksum-index cosign signature
# reproducible_scope linux x86_64 release target only
# format: sha256 two-space filename
<sha256>  <filename>
```

The artifact rows use the same two-space format as `sha256sum --check`.
The header binds the file to the release tag, the source commit, the SLSA
provenance asset name, and the Rekor transparency-log witness path.

## Verification

Download the release artifacts and the matching checksum index, then run:

```bash
sha256sum --check v1.2.3.txt
```

On macOS without GNU coreutils:

```bash
shasum -a 256 -c v1.2.3.txt
```

The workflow also writes `v<tag>.txt.sig` and `v<tag>.txt.pem` for keyless
Sigstore verification:

```bash
cosign verify-blob \
  --certificate v1.2.3.txt.pem \
  --signature v1.2.3.txt.sig \
  v1.2.3.txt
```

Rekor lookup is part of the review path. The checksum index signature is
entered in the transparency log by `cosign sign-blob`, and the release
provenance is entered by the SLSA generator as `chio-<source_sha>.intoto.jsonl`.
