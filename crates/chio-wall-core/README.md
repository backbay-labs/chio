# chio-wall-core

`chio-wall-core` defines the typed Chio-Wall control-path contracts, layered on
Chio guard and receipt truth. It holds the bounded control-path artifact and
evidence-bundle shapes that the Chio-Wall product surface exports and validates.

Use this crate for the Chio-Wall contract types. The companion-product CLI that
exercises them is `chio-wall`.
