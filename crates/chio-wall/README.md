# chio-wall

`chio-wall` is the Chio-Wall companion-product CLI built on Chio. It provides a
`control-path` command group that exports and validates the bounded Chio-Wall
control-path package together with its Chio evidence bundle, with human-readable
or JSON output.

Use this binary to produce and check Chio-Wall control-path packages. The
underlying contract types live in `chio-wall-core`.
