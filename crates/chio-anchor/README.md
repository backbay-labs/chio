# chio-anchor

`chio-anchor` is Chio's anchoring runtime and multi-lane proof normalization
over the frozen checkpoint and web3 artifact family. It covers direct EVM
root-registry publication requests and confirmation helpers,
checkpoint-to-Bitcoin super-root aggregation with OTS linkage, canonical Solana
memo publication records, and fail-closed multi-lane proof-bundle verification.

Use this crate to anchor Chio checkpoints to external chains and to verify the
resulting cross-lane proof bundles.
