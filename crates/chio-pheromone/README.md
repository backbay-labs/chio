# chio-pheromone

`chio-pheromone` defines Chio's local pheromone substrate and transit-evidence
types. Pheromones are the signed signal artifacts that Chio agents deposit and
read locally, along with the evidence that records their transit.

Use this crate for the shared pheromone and transit-evidence shapes. The local
receiver runtime is `chio-pheromone-runtime` and the networked relay is
`chio-pheromone-relay`.
