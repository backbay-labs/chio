# Programmable Sovereignty Over Reversible Action

LaTeX project for `Programmable Sovereignty Over Reversible Action`. The paper extends the type-level amendment-admission discipline to the enforcement-response side of the polity lifecycle: a reversible executive action is a type whose constructor requires a positive time-to-live witness and an action class tag, while a destructive action reduces admission to bilateral predicate intersection between a device polity and an operator polity. The load-bearing composition theorem shows that a chain of TTL-bounded amendments keeps the active constitution pinned to the baseline at every instant, preventing the predicate-ratchet failure mode. Build with `pdflatex paper.tex && bibtex paper && pdflatex paper.tex && pdflatex paper.tex` from this directory. Text is intended for CC-BY-4.0 review circulation.
