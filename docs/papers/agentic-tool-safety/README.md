# Tool Calls as Reversible-Action Admission

LaTeX project for `Tool Calls as Reversible-Action Admission: A Formal Grammar for Agentic AI Safety`. The paper argues that the safety of an LLM agent's tool call is partly a property of the substrate that admits the call: a substrate that requires every destructive tool call to carry a typed time-to-live witness and a rollback receipt slot refuses irreversible actions by construction, independent of whether training-time alignment has fully succeeded. Admission-layer safety composes orthogonally with training-layer interventions such as Constitutional AI, RLHF, and scalable oversight. Build with `pdflatex paper.tex && bibtex paper && pdflatex paper.tex && pdflatex paper.tex` from this directory. Text is intended for CC-BY-4.0 review circulation.
