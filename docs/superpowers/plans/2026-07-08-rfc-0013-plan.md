# Money-path Durability Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the economy subsystem crash-safe and fail-closed by adding a durable `payment_journal` co-located with the budget holds (written before `adapter.authorize`, advanced around capture/release, closed after the receipt persists, reconciled on boot), a boot-plus-periodic orphaned-hold sweeper, a routing consumer that feeds the discarded settlement-observer outcome into the retry/dead-letter machinery, a production `SettlementHook` driver seam, a fail-closed `Deny(CurrencyMismatch)` in `BudgetTree`, a durable SQLite EIP-3009 nonce store, and a durability caveat plus snapshot seam for `BudgetEnforcer` (closes F68, F69, F70, F71, F72, F73, F74).

**Architecture:** F70 owns the money-path recovery. RFC-0003 (the dependency) lays only the groundwork: the `chio_dispatch_intents.rail` / `.rail_authorization_id` columns, the `DispatchIntentReconciler` / `DispatchIntentResolution::MonetaryReconciled { rail_reference }` seam, `attach_dispatch_intent_rail_ref`, and `PaymentAdapter::rail_id()` (defaulted `"payment"`, X402 overrides `"x402"`). This RFC adds the money-path state machine: a `payment_journal` table in the budget-store SQLite database (so the hold write and journal write commit in ONE `TransactionBehavior::Immediate` transaction), a boot reconciler that resolves every incomplete journal row deterministically (never a guessed capture/release), and four smaller fail-closed corrections. Every recoverable authorization record is durable BEFORE the effecting action, the settle action is durable BEFORE the rail moves money (so reconciliation replays the exact operation), and nonce pruning stays out of the record path.

**Tech Stack:** Rust workspace crates `chio-store-sqlite` (rusqlite via r2d2/r2d2_sqlite pools; `SqliteBudgetStore` with per-write `TransactionBehavior::Immediate`; `SqliteDeadLetterStore`; loom via the `chio_store_sqlite_loom` cfg; proptest 1.10, tempfile, criterion dev-deps), `chio-kernel` (`PaymentAdapter`, `BudgetStore` trait, `finalize_budgeted_tool_output_with_cost_and_metadata`, `authorize_payment_if_needed`, `record_chio_receipt`, `run_settlement_observer`, `RetentionMaintenanceHandle`-style thread handles, RFC-0003 `DispatchIntentReconciler`; loom via `chio_kernel_loom`; proptest 1.10), `chio-settle` (`SettlementHook`, `SettlementOutcome`, `classify_attempt`/`RetryPolicy`/`RetryDecision`/`DeadLetterRecord`, `Eip3009NonceStore`), `chio-metering` (`BudgetTree`, `BudgetEnforcer`), `chio-cli` (clap `Commands`), `chio-metrics-spec` (`MetricDescriptor` `describe!` registry with golden `metrics.snapshot`).

```rust
//! retry envelope plus the existing dead-letter store, opened alongside the

use r2d2_sqlite::SqliteConnectionManager;

use crate::dead_letters::{DeadLetterStoreError, SqliteDeadLetterStore};

const SETTLE_ATTEMPTS_MIGRATION: &str = r#"
CREATE TABLE IF NOT EXISTS settle_attempts (
    receipt_id      TEXT PRIMARY KEY,
    finalized_at    INTEGER NOT NULL,
    attempts        INTEGER NOT NULL,
    next_visible_at INTEGER NOT NULL,
    last_reason     TEXT,
    updated_at      INTEGER NOT NULL
);
CREATE INDEX IF NOT EXISTS idx_settle_attempts_visible ON settle_attempts(next_visible_at);

/// The F68 retry sink: `settle_attempts` + the dead-letter store on one pool.
pub struct SqliteSettlementRetryStore {
    pool: Pool<SqliteConnectionManager>,
    dead_letters: SqliteDeadLetterStore,
}

impl SqliteSettlementRetryStore {
    /// Open the retry sink in the same database as `store` (mirrors
    /// `SqliteDeadLetterStore::open_alongside`).
    pub fn open_alongside(
        store: &crate::SqliteReceiptStore,
    ) -> Result<Self, SettlementRetryError> {
        let dead_letters = SqliteDeadLetterStore::open_alongside(store).map_err(map_dl_err)?;
        let pool = store.pool_handle_for_settle_attempts();
        {
            let conn = pool.get().map_err(|e| SettlementRetryError::Backend(e.to_string()))?;
            conn.execute_batch(SETTLE_ATTEMPTS_MIGRATION)
                .map_err(|e| SettlementRetryError::Backend(e.to_string()))?;
        }
        Ok(Self { pool, dead_letters })
    }

    fn now_unix_secs() -> u64 {
        std::time::SystemTime::now()
            .duration_since(std::time::UNIX_EPOCH)
            .map(|d| d.as_secs())
            .unwrap_or(0)
    }
}

fn map_dl_err(error: DeadLetterStoreError) -> SettlementRetryError {
    match error {
        DeadLetterStoreError::Conflict(m) => SettlementRetryError::Conflict(m),
        other => SettlementRetryError::Backend(other.to_string()),
    }
}

fn u64_from_i64(value: i64) -> u64 {
    value.max(0) as u64
}

impl SettlementRetryStore for SqliteSettlementRetryStore {
    fn load_attempt(
        &self,
        receipt_id: &str,
    ) -> Result<Option<SettleAttemptRecord>, SettlementRetryError> {
        let conn = self.pool.get().map_err(|e| SettlementRetryError::Backend(e.to_string()))?;
        let row = conn
            .query_row(
                "SELECT receipt_id, finalized_at, attempts, next_visible_at, last_reason \
                 FROM settle_attempts WHERE receipt_id = ?1",
                rusqlite::params![receipt_id],
                |row| {
                    Ok(SettleAttemptRecord {
                        receipt_id: row.get::<_, String>(0)?,
                        finalized_at: u64_from_i64(row.get::<_, i64>(1)?),
                        attempts: row.get::<_, i64>(2)?.max(0) as u32,
                        next_visible_at: u64_from_i64(row.get::<_, i64>(3)?),
                        last_reason: row.get::<_, Option<String>>(4)?,
                    })
                },
            )
            .optional_result()?;
        Ok(row)
    }

    fn upsert_attempt(&self, record: &SettleAttemptRecord) -> Result<(), SettlementRetryError> {
        let conn = self.pool.get().map_err(|e| SettlementRetryError::Backend(e.to_string()))?;
        conn.execute(
            "INSERT INTO settle_attempts \
             (receipt_id, finalized_at, attempts, next_visible_at, last_reason, updated_at) \
             VALUES (?1, ?2, ?3, ?4, ?5, ?6) \
             ON CONFLICT(receipt_id) DO UPDATE SET \
               attempts = excluded.attempts, \
               next_visible_at = excluded.next_visible_at, \
               last_reason = excluded.last_reason, \
               updated_at = excluded.updated_at",
            rusqlite::params![
                record.receipt_id,
                record.finalized_at as i64,
                record.attempts as i64,
                record.next_visible_at as i64,
                record.last_reason,
                Self::now_unix_secs() as i64,
            ],
        )
        .map_err(|e| SettlementRetryError::Backend(e.to_string()))?;
        Ok(())
    }

    fn clear_attempt(&self, receipt_id: &str) -> Result<(), SettlementRetryError> {
        let conn = self.pool.get().map_err(|e| SettlementRetryError::Backend(e.to_string()))?;
        conn.execute(
            "DELETE FROM settle_attempts WHERE receipt_id = ?1",
            rusqlite::params![receipt_id],
        )
        .map_err(|e| SettlementRetryError::Backend(e.to_string()))?;
        Ok(())
    }

    fn insert_dead_letter(
        &self,
        record: &chio_settle::DeadLetterRecord,
    ) -> Result<bool, SettlementRetryError> {
        self.dead_letters.insert(record).map_err(map_dl_err)
    }

    fn due_attempts(
        &self,
        now_unix_secs: u64,
        limit: usize,
    ) -> Result<Vec<SettleAttemptRecord>, SettlementRetryError> {
        let conn = self.pool.get().map_err(|e| SettlementRetryError::Backend(e.to_string()))?;
        let mut stmt = conn
            .prepare(
                "SELECT receipt_id, finalized_at, attempts, next_visible_at, last_reason \
                 FROM settle_attempts WHERE next_visible_at <= ?1 \
                 ORDER BY next_visible_at ASC LIMIT ?2",
            )
            .map_err(|e| SettlementRetryError::Backend(e.to_string()))?;
        let rows = stmt
            .query_map(rusqlite::params![now_unix_secs as i64, limit as i64], |row| {
                Ok(SettleAttemptRecord {
                    receipt_id: row.get::<_, String>(0)?,
                    finalized_at: u64_from_i64(row.get::<_, i64>(1)?),
                    attempts: row.get::<_, i64>(2)?.max(0) as u32,
                    next_visible_at: u64_from_i64(row.get::<_, i64>(3)?),
                    last_reason: row.get::<_, Option<String>>(4)?,
                })
            })
            .map_err(|e| SettlementRetryError::Backend(e.to_string()))?;
        let mut out = Vec::new();
        for row in rows {
            out.push(row.map_err(|e| SettlementRetryError::Backend(e.to_string()))?);
        }
        Ok(out)
    }
}

    }
```

```rust
//! loom model of the F68 settlement routing consumer (RFC-0013). loom cannot
//! execute SQLite, so this models the attempt-counter + dead-letter idempotency
//! protocol: a routing thread that upserts an attempt and a driver-drain thread
//! that reads the attempt and dead-letters it. Invariant: after both threads,
//! the receipt has exactly one terminal record (either one attempt row OR one
//! dead-letter), never a lost update and never two dead-letters.
//!
//! Run: RUSTFLAGS="--cfg chio_store_sqlite_loom" cargo test -p chio-store-sqlite --test loom_settlement_routing --release
#![cfg_attr(not(any(loom, chio_store_sqlite_loom)), allow(dead_code))]

#[cfg(any(loom, chio_store_sqlite_loom))]
mod model {
    use loom::sync::atomic::{AtomicU64, Ordering};
    use loom::sync::{Arc, Mutex};
    use loom::thread;

    #[test]
    fn routing_and_drain_never_lose_or_double_count() {
        loom::model(|| {
            // dead_letters models a set keyed by receipt id (0 or 1 rows).
            let dead_letters = Arc::new(Mutex::new(0u32));
            let attempts = Arc::new(AtomicU64::new(0));
            let cleared = Arc::new(AtomicU64::new(0));

            let dl_a = Arc::clone(&dead_letters);
            let at_a = Arc::clone(&attempts);
            let t1 = thread::spawn(move || {
                // Routing: record a retry attempt (idempotent upsert to 1).
                at_a.store(1, Ordering::SeqCst);
                let _ = &dl_a;
            });

            let dl_b = Arc::clone(&dead_letters);
            let cl_b = Arc::clone(&cleared);
            let t2 = thread::spawn(move || {
                // Driver drain: dead-letter, then clear the attempt. The
                // dead-letter insert is idempotent (INSERT OR IGNORE), modeled
                // as set-to-1 under the mutex.
                let mut guard = dl_b.lock().unwrap();
                if *guard == 0 {
                    *guard = 1;
                }
                cl_b.store(1, Ordering::SeqCst);
            });

            t1.join().unwrap();
            t2.join().unwrap();

            // Exactly one dead-letter, never two.
            assert!(*dead_letters.lock().unwrap() <= 1, "double dead-letter");
            // The attempt was either recorded or cleared, never lost silently:
            // at least one of the two writes is observable.
            assert!(
                attempts.load(Ordering::SeqCst) == 1 || cleared.load(Ordering::SeqCst) == 1,
                "attempt update lost"
            );
        });
    }
}
```

```rust
    fn advance_payment_journal(
        &self,
        request_id: &str,
        expected: chio_kernel::payment::PaymentJournalState,
        next: chio_kernel::payment::PaymentJournalState,
        authorization_id: Option<&str>,
        transaction_id: Option<&str>,
        settle: Option<chio_kernel::payment::PaymentSettleIntent>,
    ) -> Result<(), BudgetStoreError> {
        use chio_kernel::payment::PaymentJournalState as St;
        // Fail-closed guardrail: a Settling advance MUST carry a settle intent;
        // any other transition MUST NOT.
        if next == St::Settling && settle.is_none() {
            return Err(BudgetStoreError::Invariant(
                "advance to Settling requires a settle intent".to_string(),
            ));
        }
        if next != St::Settling && settle.is_some() {
            return Err(BudgetStoreError::Invariant(
                "settle intent is only valid on the Settling transition".to_string(),
            ));
        }
        let now = now_unix_ms();
        let mut connection = self.connection()?;
        let transaction =
            connection.transaction_with_behavior(TransactionBehavior::Immediate)?;
        let (settle_action, settle_amount) = match settle {
            Some(intent) => (Some(settle_action_str(intent.action)), intent.amount_units),
            None => (None, None),
        };
        let changed = transaction.execute(
            "UPDATE payment_journal SET \
               state = ?1, \
               authorization_id = COALESCE(?2, authorization_id), \
               transaction_id = COALESCE(?3, transaction_id), \
               settle_action = COALESCE(?4, settle_action), \
               settle_amount_units = COALESCE(?5, settle_amount_units), \
               updated_at = ?6 \
             WHERE request_id = ?7 AND state = ?8",
            rusqlite::params![
                journal_state_str(next),
                authorization_id,
                transaction_id,
                settle_action,
                settle_amount.map(|v| v as i64),
                now as i64,
                request_id,
                journal_state_str(expected),
            ],
        )?;
        if changed == 0 {
            return Err(BudgetStoreError::Invariant(format!(
                "payment journal advance conflict for {request_id}: expected state {:?}",
                expected
            )));
        }
        transaction.commit()?;
        Ok(())
    }

        use chio_kernel::payment::PaymentJournalState as St;
        let now = now_unix_ms();
```

```rust
//! Boot reconciliation of the payment journal (RFC-0013 F70). Deterministic per
//! row (no discretion, mirroring ADR-0015 D3/D5): every request_id resolves to
//! exactly one of {closed-attested, closed-reconciled, released, ReconcileFailed
//! incident}, never a silent non-terminal row and never a double capture.

use crate::kernel::ChioKernel;
use crate::payment::{PaymentJournalRecord, PaymentJournalState, PaymentSettleAction};
use crate::KernelError;

/// Terminal outcome of reconciling one incomplete journal row.
#[derive(Debug, Clone, PartialEq, Eq)]
pub enum PaymentReconcileOutcome {
    /// Money moved and an attested receipt already exists; closed.
    ClosedAttested,
    /// Money moved; a reconciliation receipt was emitted for the rail reference.
    ClosedReconciled { rail_reference: String },
    /// Funds were only held and were released; closed.
    Released,
    /// Could not settle or determine the outcome; operator incident raised.
    ReconcileFailed { detail: String },
}

/// Summary of a boot reconciliation pass.
#[derive(Debug, Clone, Default, PartialEq, Eq)]
pub struct PaymentReconcileReport {
    pub resolved: u64,
    pub reconcile_failed: u64,
}

impl ChioKernel {
    /// Reconcile every incomplete payment-journal row older than the horizon.
    pub fn reconcile_payment_journal(
        &self,
        horizon_secs: u64,
    ) -> Result<PaymentReconcileReport, KernelError> {
        let now_ms = std::time::SystemTime::now()
            .duration_since(std::time::UNIX_EPOCH)
            .map(|d| d.as_millis() as u64)
            .unwrap_or(0);
        let cutoff = now_ms.saturating_sub(horizon_secs.saturating_mul(1_000));
        let rows = self
            .with_budget_store(|store| {
                store.list_incomplete_payment_journal(cutoff).map_err(KernelError::from)
            })?;
        let mut report = PaymentReconcileReport::default();
        for record in &rows {
            match resolve_incomplete_payment_journal_row(self, record)? {
                PaymentReconcileOutcome::ReconcileFailed { detail } => {
                    self.with_budget_store(|store| {
                        store
                            .advance_payment_journal(
                                &record.request_id,
                                record.state,
                                PaymentJournalState::ReconcileFailed,
                                None,
                                None,
                                None,
                            )
                            .map_err(KernelError::from)
                    })?;
                    tracing::error!(
                        request_id = %record.request_id,
                        rail = %record.rail,
                        authorization_id = ?record.authorization_id,
                        %detail,
                        "payment reconcile failed; operator incident"
                    );
                    report.reconcile_failed += 1;
                }
                _ => {
                    self.with_budget_store(|store| {
                        store.close_payment_journal(&record.request_id).map_err(KernelError::from)
                    })?;
                    report.resolved += 1;
                }
            }
        }
        Ok(report)
    }
}

/// Idempotent shared resolver. Called by the boot pass and by the RFC-0003
/// monetary reconciler bridge. Never selects a new amount: a Settling row
/// replays exactly its recorded settle_action/settle_amount_units.
pub(crate) fn resolve_incomplete_payment_journal_row(
    kernel: &ChioKernel,
    record: &PaymentJournalRecord,
) -> Result<PaymentReconcileOutcome, KernelError> {
    let Some(adapter) = kernel.payment_adapter.as_ref() else {
        return Ok(PaymentReconcileOutcome::ReconcileFailed {
            detail: "no payment adapter configured for reconcile".to_string(),
        });
    };
    match record.state {
        PaymentJournalState::HoldPlaced => {
            // authorize may or may not have fired; no authorization_id durable.
            match adapter.settlement_state(&record.request_id, record.authorization_id.as_deref()) {
                Ok(result) => {
                    // The rail reports a hold/settlement: record the id, then
                    // release the hold (no price was chosen). Idempotent.
                    let auth = result.transaction_id.clone();
                    kernel.with_budget_store(|store| {
                        store
                            .advance_payment_journal(
                                &record.request_id,
                                PaymentJournalState::HoldPlaced,
                                PaymentJournalState::Authorized,
                                Some(&auth),
                                None,
                                None,
                            )
                            .map_err(KernelError::from)
                    })?;
                    release_and_reverse(kernel, record, &auth)?;
                    Ok(PaymentReconcileOutcome::Released)
                }
                Err(crate::payment::PaymentError::Unavailable(detail)) => {
                    Ok(PaymentReconcileOutcome::ReconcileFailed { detail })
                }
                Err(other) => {
                    // No such authorization on the rail: funds never moved.
                    let _ = other;
                    reverse_hold_only(kernel, record)?;
                    Ok(PaymentReconcileOutcome::Released)
                }
            }
        }
        PaymentJournalState::Authorized => {
            // authorize succeeded but no terminal action was committed. The only
            // sound, price-free completion is to release the hold.
            let Some(auth) = record.authorization_id.as_deref() else {
                return Ok(PaymentReconcileOutcome::ReconcileFailed {
                    detail: "Authorized row missing authorization_id".to_string(),
                });
            };
            release_and_reverse(kernel, record, auth)?;
            Ok(PaymentReconcileOutcome::Released)
        }
        PaymentJournalState::Settling => {
            // A terminal action IS durable; replay it exactly (idempotent).
            let Some(auth) = record.authorization_id.as_deref() else {
                return Ok(PaymentReconcileOutcome::ReconcileFailed {
                    detail: "Settling row missing authorization_id".to_string(),
                });
            };
            match record.settle_action {
                Some(PaymentSettleAction::Capture) => {
                    let Some(amount) = record.settle_amount_units else {
                        return Ok(PaymentReconcileOutcome::ReconcileFailed {
                            detail: "Settling capture row missing settle_amount_units".to_string(),
                        });
                    };
                    adapter
                        .capture(auth, amount, &record.currency, &record.request_id)
                        .map_err(|e| KernelError::Internal(format!("reconcile capture: {e}")))?;
                    let rail_reference = format!("{}:{}", record.rail, auth);
                    Ok(PaymentReconcileOutcome::ClosedReconciled { rail_reference })
                }
                Some(PaymentSettleAction::Release) => {
                    release_and_reverse(kernel, record, auth)?;
                    Ok(PaymentReconcileOutcome::Released)
                }
                None => Ok(PaymentReconcileOutcome::ReconcileFailed {
                    detail: "Settling row missing settle_action (corrupt)".to_string(),
                }),
            }
        }
        PaymentJournalState::Settled => {
            // Money moved. If an attested receipt with the same request_id
            // exists, close; otherwise emit a reconciliation receipt.
            if kernel.attested_receipt_exists_for_request(&record.request_id)? {
                Ok(PaymentReconcileOutcome::ClosedAttested)
            } else {
                let rail_reference = record
                    .authorization_id
                    .as_deref()
                    .map(|a| format!("{}:{}", record.rail, a))
                    .unwrap_or_else(|| record.rail.clone());
                kernel.emit_reconciliation_receipt(record)?;
                Ok(PaymentReconcileOutcome::ClosedReconciled { rail_reference })
            }
        }
        PaymentJournalState::Closed | PaymentJournalState::ReconcileFailed => {
            Ok(PaymentReconcileOutcome::ClosedAttested)
        }
    }
}

fn release_and_reverse(
    kernel: &ChioKernel,
    record: &PaymentJournalRecord,
    authorization_id: &str,
) -> Result<(), KernelError> {
    if let Some(adapter) = kernel.payment_adapter.as_ref() {
        adapter
            .release(authorization_id, &record.request_id)
            .map_err(|e| KernelError::Internal(format!("reconcile release: {e}")))?;
    }
    reverse_hold_only(kernel, record)
}

fn reverse_hold_only(kernel: &ChioKernel, record: &PaymentJournalRecord) -> Result<(), KernelError> {
    // Reverse the budget hold so held-but-never-captured capacity is returned
    // (fail-closed under-spend). Uses the existing reverse_budget_hold path.
    kernel.reverse_budget_hold_for_reconcile(record)
}
```

```rust
/// Bridges RFC-0003's generic boot reconcile to the money-path resolver: a
/// monetary orphan intent is resolved by looking up its payment-journal row and
/// running the deterministic completion, reporting MonetaryReconciled with the
/// rail reference (RFC-0013 F70).
pub struct MonetaryDispatchIntentReconciler<'a> {
    pub kernel: &'a ChioKernel,
}

impl<'a> crate::receipt_store::DispatchIntentReconciler for MonetaryDispatchIntentReconciler<'a> {
    fn resolve(
        &self,
        intent: &crate::receipt_store::DispatchIntentRecord,
    ) -> Result<crate::receipt_store::DispatchIntentResolution, crate::receipt_store::ReceiptStoreError>
    {
        use crate::receipt_store::{DispatchIntentResolution, SideEffectClass};
        if intent.side_effect_class != SideEffectClass::Monetary {
            // Non-monetary orphans keep RFC-0003's default outcome-unknown
            // dead-letter (this reconciler only owns the money path).
            return Ok(DispatchIntentResolution::DeadLetter {
                detail: "non-monetary orphan; deferred to generic reconcile".to_string(),
            });
        }
        let row = self
            .kernel
            .with_budget_store(|store| {
                store
                    .list_incomplete_payment_journal(u64::MAX)
                    .map_err(crate::KernelError::from)
            })
            .map_err(|e| crate::receipt_store::ReceiptStoreError::Conflict(e.to_string()))?
            .into_iter()
            .find(|r| r.request_id == intent.request_id);
        let Some(record) = row else {
            // No incomplete journal row: the money path already terminated
            // (closed or reconcile-failed). Safe to treat the intent as
            // resolved with the rail reference from the intent itself.
            let rail_reference = intent
                .rail_authorization_id
                .clone()
                .or_else(|| intent.rail.clone())
                .unwrap_or_default();
            return Ok(DispatchIntentResolution::MonetaryReconciled { rail_reference });
        };
        match resolve_incomplete_payment_journal_row(self.kernel, &record)
            .map_err(|e| crate::receipt_store::ReceiptStoreError::Conflict(e.to_string()))?
        {
            PaymentReconcileOutcome::ReconcileFailed { detail } => {
                Ok(DispatchIntentResolution::DeadLetter { detail })
            }
            PaymentReconcileOutcome::ClosedReconciled { rail_reference } => {
                Ok(DispatchIntentResolution::MonetaryReconciled { rail_reference })
            }
            PaymentReconcileOutcome::ClosedAttested => {
                let rail_reference = record
                    .authorization_id
                    .map(|a| format!("{}:{}", record.rail, a))
                    .unwrap_or(record.rail);
                Ok(DispatchIntentResolution::MonetaryReconciled { rail_reference })
            }
            PaymentReconcileOutcome::Released => Ok(DispatchIntentResolution::SafeToReplay),
        }
    }
}
```

```rust
        &self,
        older_than_unix_ms: u64,
        limit: usize,

        let connection = self.connection()?;

             FROM budget_authorization_holds \
             WHERE disposition = 'open' AND created_at <= ?1 \
             ORDER BY created_at ASC LIMIT ?2",

                    grant_index: row.get::<_, i64>(2)?.max(0) as u32,
                    remaining_exposure_units: row.get::<_, i64>(3)?.max(0) as u64,
                    created_at_unix_ms: row.get::<_, i64>(4)?.max(0) as u64,
                })

    fn expire_open_hold(&self, hold_id: &str) -> Result<bool, BudgetStoreError> {
        let mut connection = self.connection()?;
        let transaction =
            connection.transaction_with_behavior(TransactionBehavior::Immediate)?;
        // Read the open hold's remainder + owning grant inside the tx.
        let row: Option<(String, i64, i64)> = transaction
            .query_row(
                "SELECT capability_id, grant_index, remaining_exposure_units \
                 FROM budget_authorization_holds WHERE hold_id = ?1 AND disposition = 'open'",
                rusqlite::params![hold_id],
                |row| Ok((row.get(0)?, row.get(1)?, row.get(2)?)),
            )
            .optional()?;
        let Some((capability_id, grant_index, remaining)) = row else {
            return Ok(false); // idempotent: not open (already expired/reconciled/absent)
        };
        let now = now_unix_ms() as i64;
        // Release capacity: subtract the remainder from total_cost_exposed. Never
        // touch total_cost_realized_spend (fail-closed under-spend, ADR-0006).
        transaction.execute(
            "UPDATE capability_grant_budgets \
             SET total_cost_exposed = MAX(total_cost_exposed - ?1, 0), updated_at = ?2 \
             WHERE capability_id = ?3 AND grant_index = ?4",
            rusqlite::params![remaining, now, capability_id, grant_index],
        )?;
        transaction.execute(
            "UPDATE budget_authorization_holds \
             SET disposition = 'expired', remaining_exposure_units = 0, updated_at = ?1 \
             WHERE hold_id = ?2",
            rusqlite::params![now, hold_id],
        )?;
        // Append the expire_hold mutation event (reuse the existing event-insert
        // helper used by reverse/reduce/settle paths).
        append_mutation_event_tx(
            &transaction,
            &capability_id,
            grant_index,
            BudgetMutationKind::ExpireHold,
            remaining,
            0,
            Some(hold_id),
            now,
        )?;
        transaction.commit()?;
        Ok(true)
    }

    fn open_hold_count(&self) -> Result<u64, BudgetStoreError> {
        let connection = self.connection()?;
        let count: i64 = connection.query_row(
            "SELECT COUNT(*) FROM budget_authorization_holds WHERE disposition = 'open'",
            [],
            |row| row.get(0),
        )?;
        Ok(count.max(0) as u64)
    }
```

```rust
pub struct BudgetHoldSweepHandle {
    stop: std::sync::Arc<std::sync::atomic::AtomicBool>,
    join: Option<std::thread::JoinHandle<()>>,
}

impl BudgetHoldSweepHandle {
    pub(crate) fn spawn(
        budget_store: std::sync::Arc<dyn crate::budget_store::BudgetStore>,
        interval_secs: u64,
        horizon_secs: u64,
        batch: usize,
    ) -> Self {
        let stop = std::sync::Arc::new(std::sync::atomic::AtomicBool::new(false));
        let worker_stop = std::sync::Arc::clone(&stop);
        let join = std::thread::spawn(move || {
            let interval = std::time::Duration::from_secs(interval_secs.max(1));
            loop {
                sweep_once(budget_store.as_ref(), horizon_secs, batch);
                let mut waited = std::time::Duration::ZERO;
                let slice = std::time::Duration::from_millis(200);
                while waited < interval
                    && !worker_stop.load(std::sync::atomic::Ordering::SeqCst)
                {
                    std::thread::sleep(slice);
                    waited += slice;
                }
                if worker_stop.load(std::sync::atomic::Ordering::SeqCst) {
                    break;
                }
            }
        });
        Self { stop, join: Some(join) }
    }
}

impl Drop for BudgetHoldSweepHandle {
    fn drop(&mut self) {
        self.stop.store(true, std::sync::atomic::Ordering::SeqCst);
        if let Some(join) = self.join.take() {
            let _ = join.join();
        }
    }
}

fn sweep_once(store: &dyn crate::budget_store::BudgetStore, horizon_secs: u64, batch: usize) {
    let now_ms = std::time::SystemTime::now()
        .duration_since(std::time::UNIX_EPOCH)
        .map(|d| d.as_millis() as u64)
        .unwrap_or(0);
    let cutoff = now_ms.saturating_sub(horizon_secs.saturating_mul(1_000));
    match store.list_open_holds_older_than(cutoff, batch) {
        Ok(holds) => {
            for hold in holds {
                match store.expire_open_hold(&hold.hold_id) {
                    Ok(true) => crate::kernel::budget_sweep::record_hold_expired(),
                    Ok(false) => {}
                    Err(error) => tracing::warn!(hold_id = %hold.hold_id, %error,
                        "expire_open_hold failed; will retry next sweep"),
                }
            }
        }
        Err(error) => tracing::warn!(%error, "list_open_holds_older_than failed; will retry"),
    }
    if let Ok(count) = store.open_hold_count() {
        crate::kernel::budget_sweep::set_open_holds_gauge(count);
    }
}
```

```rust
//! is the sole entry point that drops entries, so replay decisions stay
//! decoupled from the wall clock (matching the trait contract at payments.rs).

use std::path::Path;

use chio_settle::{Eip3009NonceStore, NonceOutcome, SettlementError};
use r2d2::Pool;
use r2d2_sqlite::SqliteConnectionManager;

const EIP3009_MIGRATION: &str = r#"
CREATE TABLE IF NOT EXISTS eip3009_nonces (
    from_address TEXT NOT NULL,
    nonce_key    TEXT NOT NULL,
    retain_until INTEGER NOT NULL,
    PRIMARY KEY (from_address, nonce_key)
);
CREATE INDEX IF NOT EXISTS idx_eip3009_nonces_retain_until ON eip3009_nonces(retain_until);
"#;

/// Durable EIP-3009 nonce store.
pub struct SqliteEip3009NonceStore {
    pool: Pool<SqliteConnectionManager>,
}

impl SqliteEip3009NonceStore {
    pub fn open(path: impl AsRef<Path>) -> Result<Self, SettlementError> {
        let manager = SqliteConnectionManager::file(path.as_ref());
        let pool = Pool::new(manager)
            .map_err(|e| SettlementError::InvalidBinding(format!("eip3009 pool: {e}")))?;
        Self::open_with_pool(pool)
    }

    pub fn open_with_pool(pool: Pool<SqliteConnectionManager>) -> Result<Self, SettlementError> {
        {
            let conn = pool
                .get()
                .map_err(|e| SettlementError::InvalidBinding(format!("eip3009 conn: {e}")))?;
            conn.execute_batch(EIP3009_MIGRATION)
                .map_err(|e| SettlementError::InvalidBinding(format!("eip3009 migrate: {e}")))?;
        }
        Ok(Self { pool })
    }
}

// Normalize a key component exactly as chio_settle::canonicalize_nonce_key_component
// does (trim, strip a leading 0x/0X, lowercase), so casing/prefix variants map to
// the same row.
fn canonicalize(value: &str) -> String {
    let trimmed = value.trim();
    let stripped = trimmed
        .strip_prefix("0x")
        .or_else(|| trimmed.strip_prefix("0X"))
        .unwrap_or(trimmed);
    stripped.to_ascii_lowercase()
}

impl Eip3009NonceStore for SqliteEip3009NonceStore {
    fn record_if_fresh(
        &self,
        from_address: &str,
        nonce: &str,
        retain_until_unix_seconds: u64,
    ) -> Result<NonceOutcome, SettlementError> {
        let from = canonicalize(from_address);
        let key = canonicalize(nonce);
        let mut conn = self
            .pool
            .get()
            .map_err(|e| SettlementError::InvalidBinding(format!("eip3009 conn: {e}")))?;
        let tx = conn
            .transaction_with_behavior(rusqlite::TransactionBehavior::Immediate)
            .map_err(|e| SettlementError::InvalidBinding(format!("eip3009 tx: {e}")))?;
        // Atomic single-use: DO NOTHING on a present key so two parallel replays
        // cannot both observe Fresh. NEVER prune here (no `now` argument).
        let changed = tx
            .execute(
                "INSERT INTO eip3009_nonces (from_address, nonce_key, retain_until) \
                 VALUES (?1, ?2, ?3) ON CONFLICT(from_address, nonce_key) DO NOTHING",
                rusqlite::params![from, key, retain_until_unix_seconds as i64],
            )
            .map_err(|e| SettlementError::InvalidBinding(format!("eip3009 insert: {e}")))?;
        tx.commit()
            .map_err(|e| SettlementError::InvalidBinding(format!("eip3009 commit: {e}")))?;
        Ok(if changed == 1 { NonceOutcome::Fresh } else { NonceOutcome::Replayed })
    }

    fn gc_expired(&self, now_unix_seconds: u64) -> Result<usize, SettlementError> {
        let conn = self
            .pool
            .get()
            .map_err(|e| SettlementError::InvalidBinding(format!("eip3009 conn: {e}")))?;
        let removed = conn
            .execute(
                "DELETE FROM eip3009_nonces WHERE retain_until < ?1",
                rusqlite::params![now_unix_seconds as i64],
            )
            .map_err(|e| SettlementError::InvalidBinding(format!("eip3009 gc: {e}")))?;
        Ok(removed)
    }

    fn len(&self) -> Result<usize, SettlementError> {
        let conn = self
            .pool
            .get()
            .map_err(|e| SettlementError::InvalidBinding(format!("eip3009 conn: {e}")))?;
        let count: i64 = conn
            .query_row("SELECT COUNT(*) FROM eip3009_nonces", [], |row| row.get(0))
            .map_err(|e| SettlementError::InvalidBinding(format!("eip3009 count: {e}")))?;
        Ok(count.max(0) as usize)
    }
}
```
