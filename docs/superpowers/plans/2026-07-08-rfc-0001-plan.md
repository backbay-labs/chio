# RFC-0001 Hot-path Deadlines and Watchdogs Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Bound every await on the Chio mediation hot path (guard pipeline, tool dispatch, receipt append, budget-write quorum wait) with a configurable wall-clock budget that fails closed through the shared RFC-0002 unwind path, offload synchronous guards to `spawn_blocking` so a blocking guard cannot pin an async worker, move checkpointing off the receipt write lock, and make receipt-writer liveness (not just config presence) a loud, pre-dispatch gate that denies before any tool side effect (closes F01, F07, F14, and implements deep-dive D1).

**Architecture:** Three new opt-in wall-clock budgets live on a `HotPathDeadlineConfig` nested in the runtime `KernelConfig`. The guard pipeline keeps its synchronous fail-closed core (`run_guards`) but a new async wrapper (`run_guards_within_budget`) offloads it to `tokio::task::spawn_blocking` and wraps it in `tokio::time::timeout` when a budget or per-guard override applies; the tool dispatch call gains a `tokio::time::timeout` wrapper whose expiry runs the exact same abort arm as `KernelError::RequestCancelled` (reverse monetary holds, retain-and-mark the runtime-admission reservation per RFC-0002, emit one signed `Cancelled` receipt). On the receipt path a bounded `append_with_timeout` caps how long the kernel-wide `receipt_store_write_lock` is held, checkpointing moves to a background `tokio::sync::watch`-driven drain task, and a writer-liveness watchdog (opt-in, wired by the hosting edge) publishes a verdict the pre-dispatch readiness gate reads. F14 wraps the whole quorum wait in `tokio::time::timeout`.

**Tech Stack:** Rust workspace crates `chio-kernel` (runtime `KernelConfig`, `KernelError`, `ChioKernel`, guard pipeline, dispatch, receipt persistence, `ReceiptStore` trait, `arc_swap`, `tokio` time/task, `loom` + `proptest` dev-deps), `chio-store-sqlite` (group-commit `ReceiptCommitActor` over `std::sync::mpsc`, `ReceiptWriterHealth` counters), `chio-config` (TOML schema + fail-closed `validate`), `chio-control-plane` (budget-write quorum loop), `chio-edge-metrics` (Prometheus text surface). Kernel async tests use `#[tokio::test(flavor = "multi_thread", worker_threads = 2)]` and the `include!`-based test harness in `crates/kernel/chio-kernel/src/kernel/tests/` (`make_config`, `make_kernel`, `make_capability`, `make_request_with_arguments`, `register_tool_server`, `add_guard`).

```rust
use std::collections::BTreeMap;
use std::time::Duration;

use super::construction::KernelBuildError;

/// Wall-clock budgets for the mediation hot path. See RFC-0001. All values are
/// milliseconds; `0` means "no deadline" for the opt-in guard and dispatch
/// budgets so existing deployments are byte-for-byte unchanged until an
/// operator sets one. The receipt-append budget may not be `0`.
#[derive(Debug, Clone)]
pub struct HotPathDeadlineConfig {
    /// Budget for the whole guard pipeline, enforced around `run_guards`.
    /// `0` disables. Default `0` (preserves current inline behavior).
    pub guard_pipeline_budget_ms: u64,
    /// Per-guard overrides keyed by `Guard::name()`. Any entry forces per-guard
    /// offload; `0` disables the override for that guard.
    pub per_guard_budget_ms: BTreeMap<String, u64>,
    /// Offload the guard pipeline to `spawn_blocking` even with no budget set,
    /// so a blocking guard never pins an async worker. Default `false`.
    pub always_offload_guards: bool,
    /// Default per-dispatch budget. `0` disables. Default `0`.
    pub dispatch_budget_ms: u64,
    /// Per-tool-server dispatch overrides keyed by `ServerId` string.
    pub per_server_dispatch_budget_ms: BTreeMap<String, u64>,
    /// Watchdog bound on one receipt-append round trip through the commit
    /// actor. Must be `>= MIN_RECEIPT_APPEND_BUDGET_MS`. Default 5000.
    pub receipt_append_budget_ms: u64,
    /// Writer-liveness watchdog poll cadence and staleness threshold.
    pub receipt_writer_poll_ms: u64,
    pub receipt_writer_stall_ms: u64,
}

pub const DEFAULT_RECEIPT_APPEND_BUDGET_MS: u64 = 5_000;
pub const MIN_RECEIPT_APPEND_BUDGET_MS: u64 = 250;
pub const DEFAULT_RECEIPT_WRITER_POLL_MS: u64 = 1_000;
pub const DEFAULT_RECEIPT_WRITER_STALL_MS: u64 = 10_000;

impl Default for HotPathDeadlineConfig {
    fn default() -> Self {
        Self {
            guard_pipeline_budget_ms: 0,
            per_guard_budget_ms: BTreeMap::new(),
            always_offload_guards: false,
            dispatch_budget_ms: 0,
            per_server_dispatch_budget_ms: BTreeMap::new(),
            receipt_append_budget_ms: DEFAULT_RECEIPT_APPEND_BUDGET_MS,
            receipt_writer_poll_ms: DEFAULT_RECEIPT_WRITER_POLL_MS,
            receipt_writer_stall_ms: DEFAULT_RECEIPT_WRITER_STALL_MS,
        }
    }
}

impl HotPathDeadlineConfig {
    /// Fail-closed load-time validation. Called from `ChioKernel::try_new` and
    /// mirrored in chio-config's `validate_kernel`.
    pub fn validate(&self) -> Result<(), KernelBuildError> {
        if self.receipt_append_budget_ms < MIN_RECEIPT_APPEND_BUDGET_MS {
            return Err(KernelBuildError::InvalidDeadlineConfig(format!(
                "receipt_append_budget_ms must be >= {MIN_RECEIPT_APPEND_BUDGET_MS}"
            )));
        }
        if self.receipt_writer_poll_ms == 0 || self.receipt_writer_stall_ms == 0 {
            return Err(KernelBuildError::InvalidDeadlineConfig(
                "receipt writer poll and stall thresholds must be non-zero".to_string(),
            ));
        }
        Ok(())
    }
```

```rust
    /// `spawn_blocking` and bounds with `tokio::time::timeout` when a budget or
    /// per-guard override applies, or when `always_offload_guards` is set;
    /// otherwise keeps today's inline behavior. Falls through to inline when no
    /// Tokio runtime is present (the compute-only no-runtime path).
    pub(crate) async fn run_guards_within_budget(
        &self,
        request: &ToolCallRequest,
        scope: &ChioScope,
        session_filesystem_roots: Option<&[String]>,
        matched_grant_index: Option<usize>,
    ) -> Result<Vec<chio_core::receipt::metadata::GuardEvidence>, GuardRunError> {
        let has_per_guard = !self.config.deadlines.per_guard_budget_ms.is_empty();
        let pipeline_budget = self.config.deadlines.guard_pipeline_budget();
        let want_offload = pipeline_budget.is_some()
            || has_per_guard
            || self.config.deadlines.always_offload_guards;

        if !want_offload || tokio::runtime::Handle::try_current().is_err() {
            return self.run_guards(request, scope, session_filesystem_roots, matched_grant_index);
        }

        let owned = std::sync::Arc::new(OwnedGuardInvocation {
            request: request.clone(),
            scope: scope.clone(),
            session_filesystem_roots: session_filesystem_roots.map(<[String]>::to_vec),
            matched_grant_index,
        });

        if has_per_guard {
            return self.run_guards_per_guard_offloaded(&owned).await;
        }

        let guards = std::sync::Arc::clone(&self.guards);
        let owned_for_task = std::sync::Arc::clone(&owned);
        let join = tokio::task::spawn_blocking(move || run_guards_owned(&guards, &owned_for_task));
        match pipeline_budget {
            Some(budget) => match tokio::time::timeout(budget, join).await {
                Ok(Ok(result)) => result,
                Ok(Err(join_err)) => Err(GuardRunError::new(
                    KernelError::Internal(format!("guard task join failed: {join_err}")),
                    Vec::new(),

                Err(_elapsed) => Err(GuardRunError::new(
                    KernelError::HotPathDeadlineExceeded {
                        stage: HotPathStage::GuardPipeline,
                        budget_ms: budget_ms_saturating(budget),
                    },
                    Vec::new(),
                )),
            },
            None => match join.await {
                Ok(result) => result,
                Err(join_err) => Err(GuardRunError::new(
                    KernelError::Internal(format!("guard task join failed: {join_err}")),
                    Vec::new(),
                )),
            },
        }
```

```rust
    fn append_with_timeout(
        &self,
        receipt: ChioReceipt,
        raw_json: String,
        timeout: Duration,
    ) -> Result<u64, ReceiptStoreError> {
        // Identical to append() through try_send (increment inflight, enqueue,
        // count saturation/disconnect), then bound the wait.
        self.health.inflight.fetch_add(1, Ordering::SeqCst);
        let (response, result) = std::sync::mpsc::channel();
        match self.sender.try_send(ReceiptCommitJob::new(receipt, raw_json, response)) {
            Ok(()) => {
                self.health.accepted_total.fetch_add(1, Ordering::SeqCst);
            }
            Err(std::sync::mpsc::TrySendError::Full(_)) => {
                atomic_saturating_sub(&self.health.inflight, 1);
                self.health.saturated_total.fetch_add(1, Ordering::SeqCst);
                return Err(receipt_actor_saturated_error());
            }
            Err(std::sync::mpsc::TrySendError::Disconnected(_)) => {
                atomic_saturating_sub(&self.health.inflight, 1);
                return Err(receipt_actor_unavailable_error());
            }
        }

            Ok(inner) => inner,

                // once when it drains the batch. Decrementing on the timeout
```

```rust
//! Background checkpoint drain (RFC-0001). A `tokio::sync::watch` sender
//! coalesces a burst of due sequences into the latest one; a lazily-spawned
//! task drains it and runs the (synchronous) checkpoint inside `spawn_blocking`
//! so it never runs under the caller's receipt write lock and never pins an
//! async worker. Lazy spawn mirrors `signing_task.rs` so `ChioKernel::new` in
//! sync / no-runtime contexts never panics for lack of a runtime.

use std::sync::{Arc, Mutex};

use tokio::sync::watch;
use tokio::task::JoinHandle;

use super::ChioKernel;

pub(crate) struct CheckpointDrainHandle {
    sender: watch::Sender<u64>,
    join: Mutex<Option<JoinHandle<()>>>,
    spawn_gate: Mutex<()>,
}

impl CheckpointDrainHandle {
    pub(crate) fn new() -> Self {
        let (sender, _receiver) = watch::channel(0u64);
        Self {
            sender,
            join: Mutex::new(None),
            spawn_gate: Mutex::new(()),
        }
    }

    /// Trigger a checkpoint for `seq`. In an async context, lazily spawns the
    /// drain task (guarded) and publishes `seq`. With no runtime, runs the
    /// checkpoint inline (still OFF the caller's write lock; the no-runtime
    /// compute path has no concurrency to protect).
    pub(crate) fn notify(&self, kernel: &Arc<ChioKernel>, seq: u64) {
        if tokio::runtime::Handle::try_current().is_err() {
            let _ = kernel.run_due_checkpoint(seq);
            return;
        }
        self.ensure_spawned(kernel);
        let _ = self.sender.send(seq);
    }

    fn ensure_spawned(&self, kernel: &Arc<ChioKernel>) {
        let _gate = match self.spawn_gate.lock() {
            Ok(gate) => gate,
            Err(poisoned) => poisoned.into_inner(),
        };
        let mut join = match self.join.lock() {
            Ok(join) => join,
            Err(poisoned) => poisoned.into_inner(),
        };
        if join.is_some() {
            return;
        }
        let mut receiver = self.sender.subscribe();
        let kernel = Arc::clone(kernel);
        let handle = tokio::spawn(async move {
            while receiver.changed().await.is_ok() {
                let seq = *receiver.borrow_and_update();
                if seq == 0 {
                    continue;
                }
                let kernel = Arc::clone(&kernel);
                let _ = tokio::task::spawn_blocking(move || kernel.run_due_checkpoint(seq)).await;
            }
        });
        *join = Some(handle);
    }

    pub(crate) async fn shutdown(&self) {
        let handle = {
            let mut join = match self.join.lock() {
                Ok(join) => join,
                Err(poisoned) => poisoned.into_inner(),
            };
            join.take()
        };
        if let Some(handle) = handle {
            handle.abort();
            let _ = handle.await;
        }
    }
}
```

```rust
//! calls `ChioKernel::spawn_receipt_writer_watchdog` in an async context. It
//! polls the store's `writer_liveness()` on a cadence and publishes the latest

use tokio::task::JoinHandle;

use crate::receipt_store::ReceiptWriterLiveness;
use super::ChioKernel;

pub(crate) struct ReceiptWriterWatchdogHandle {
    verdict: ArcSwap<ReceiptWriterLiveness>,
    join: Mutex<Option<JoinHandle<()>>>,
}

        Self {
            verdict: ArcSwap::from_pointee(ReceiptWriterLiveness::Unknown),
            join: Mutex::new(None),
        }
    }
```
