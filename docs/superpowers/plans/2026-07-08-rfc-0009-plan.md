# RFC-0009 Observability and Alerting Wiring Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn Chio's registered-but-dead observability plane into a live contract: wire every alert-referenced metric to a real emission site, pre-register known label sets at zero so absence-alerts only fire on a true scrape gap, replace the kernel `/metrics` placeholder renderer with process-global counters, mount a scrape route on every serving surface, move the SIEM/OTLP/redaction path into a production serve mode, make SIEM delivery at-least-once with persisted accounting, count every drop, make the OTEL partial-batch retry deterministic, add a receipt-log gap/lag watchdog, and gate the build so a registered alert-referenced family with no producer fails CI.

**Architecture:** A new internal `chio-metrics-spec::runtime` module adds two process-global emission primitives (`LabeledCounter`, `LabeledHistogram`) that render into the existing `descriptor_for(name)` metadata, plus a `preregister` seam that seeds known label sets at zero. Each crate that owns a truth source (chio-tower fail-open, chio-wasm-guards verdicts, chio-siem export, the OTLP ingress) owns its emission and a `render_*_prometheus()` function; serving surfaces compose those bodies through a shared helper (mirroring `chio-http-core::render_http_core_metrics_prometheus` and the pheromone-relay `ExtraMetricsHook`) and never fabricate values, preserving the ADR-0009 isolation boundary. Correctness fixes cache OTEL receipts once and resume append at a per-batch cursor (no duplicate signed ids), persist a per-exporter SIEM high-water mark in a SIEM-owned SQLite file (leaving the read-only receipt DB untouched), and a kernel watchdog turns the existing `ReceiptStoreHealthReport` into gauges.

**Tech Stack:** Rust workspace crates `chio-metrics-spec` (registry + new `runtime` module; std atomics + `Mutex<BTreeMap>`), `chio-tower` (tower `Service` layer, `axum` in dev-deps), `chio-kernel` (`/metrics` renderer, signing task, receipt-store health, `proptest`/`loom`/`criterion` dev-deps), `chio-wasm-guards` (wasmtime guard backend, span observability), `chio-siem` (`ExporterManager`, DLQ, `tokio` dev-dep; `rusqlite` for the cursor store), `chio-otel-receipt-exporter` (OTLP ingress + receipt sink; `loom` dev-dep), `chio-http-core`/`chio-api-protect`/`chio-control-plane`/`chio-mcp-remote`/`chio-pheromone-relay` (`axum` 0.8 routers), `chio-cli`/`chio-wall` (serve mode, `tracing-subscriber` env-filter), `chio-log-redact` (`RedactionLayer`), `chio-conformance` (`proptest`, conformance gates over `deploy/prometheus/*.yml`).

```rust
//! Process-global metric emission primitives (RFC-0009 Part A).
//!
//! `LabeledCounter`/`LabeledGauge`/`LabeledHistogram` are lock-free on read of a
//! resolved cell and mutex-guarded only when a new label set first appears (cold
//! path), mirroring the chio-wasm-guards pool registry. They render into the
//! `crate::descriptor_for(name)` metadata so emitted `# HELP`/`# TYPE` cannot
//! drift from the registry. All three fail closed: a lock poison or a label
//! arity mismatch drops the sample (debug-asserted) rather than unwinding, so
//! observability never gates the mediation hot path.

use std::collections::BTreeMap;
use std::sync::atomic::{AtomicU64, Ordering};
use std::sync::{Arc, Mutex};

use crate::{descriptor_for, MetricKind};

fn escape_label_value(value: &str) -> String {
    value.replace('\\', "\\\\").replace('"', "\\\"")
}

fn render_label_set(labels: &[&'static str], values: &[String]) -> String {
    if labels.is_empty() {
        return String::new();
    }
    let mut parts = Vec::with_capacity(labels.len());
    for (label, value) in labels.iter().zip(values.iter()) {
        parts.push(format!("{label}=\"{}\"", escape_label_value(value)));
    }
    format!("{{{}}}", parts.join(","))
}

fn render_header(out: &mut String, name: &str, kind_word: &str) {
    if let Some(descriptor) = descriptor_for(name) {
        out.push_str(&format!("# HELP {name} {}\n", descriptor.help));
    }
    out.push_str(&format!("# TYPE {name} {kind_word}\n"));
}

/// Resolve `values` against `labels`; returns an owned key when the arity
/// matches, else `None` (the caller drops the sample fail-closed).
fn key_for(labels: &[&'static str], values: &[&str]) -> Option<Vec<String>> {
    if values.len() != labels.len() {
        debug_assert!(false, "metric label arity mismatch for a runtime family");
        return None;
    }
    Some(values.iter().map(|value| (*value).to_string()).collect())
}

/// A process-global counter keyed by an ordered label tuple.
pub struct LabeledCounter {
    name: &'static str,
    labels: &'static [&'static str],
    cells: Mutex<BTreeMap<Vec<String>, Arc<AtomicU64>>>,
}

impl LabeledCounter {
    #[must_use]
    pub const fn new(name: &'static str, labels: &'static [&'static str]) -> Self {
        Self {
            name,
            labels,
            cells: Mutex::new(BTreeMap::new()),
        }
    }

    fn cell(&self, values: &[&str]) -> Option<Arc<AtomicU64>> {
        let key = key_for(self.labels, values)?;
        let mut cells = self.cells.lock().ok()?;
        Some(Arc::clone(
            cells.entry(key).or_insert_with(|| Arc::new(AtomicU64::new(0))),
        ))
    }

    pub fn incr(&self, values: &[&str]) {
        self.incr_by(values, 1);
    }

    pub fn incr_by(&self, values: &[&str], delta: u64) {
        if let Some(cell) = self.cell(values) {
            cell.fetch_add(delta, Ordering::Relaxed);
        }
    }

    /// Seed the series at zero so it exists before its first event (RFC-0009
    /// contract rule 2). Idempotent: leaves an existing cell untouched.
    pub fn preregister(&self, values: &[&str]) {
        let _ = self.cell(values);
    }

    pub fn render(&self, out: &mut String) {
        render_header(out, self.name, "counter");
        let Ok(cells) = self.cells.lock() else { return };
        for (values, cell) in cells.iter() {
            out.push_str(&format!(
                "{}{} {}\n",
                self.name,
                render_label_set(self.labels, values),
                cell.load(Ordering::Relaxed)
            ));
        }
    }
}

/// A process-global gauge (set, not accumulate).
pub struct LabeledGauge {
    name: &'static str,
    labels: &'static [&'static str],
    cells: Mutex<BTreeMap<Vec<String>, Arc<AtomicU64>>>,
}

impl LabeledGauge {
    #[must_use]
    pub const fn new(name: &'static str, labels: &'static [&'static str]) -> Self {
        Self { name, labels, cells: Mutex::new(BTreeMap::new()) }
    }

    fn cell(&self, values: &[&str]) -> Option<Arc<AtomicU64>> {
        let key = key_for(self.labels, values)?;
        let mut cells = self.cells.lock().ok()?;
        Some(Arc::clone(
            cells.entry(key).or_insert_with(|| Arc::new(AtomicU64::new(0))),
        ))
    }

    pub fn set(&self, values: &[&str], value: u64) {
        if let Some(cell) = self.cell(values) {
            cell.store(value, Ordering::Relaxed);
        }
    }

    pub fn preregister(&self, values: &[&str]) {
        let _ = self.cell(values);
    }

    pub fn render(&self, out: &mut String) {

        let Ok(cells) = self.cells.lock() else { return };
        for (values, cell) in cells.iter() {
            out.push_str(&format!(

                self.name,
                render_label_set(self.labels, values),
                cell.load(Ordering::Relaxed)
            ));
        }
    }
}

struct HistogramCell {
    bucket_counts: Vec<AtomicU64>,
    sum_millis: AtomicU64,
    count: AtomicU64,
}

/// A process-global histogram over the registry-declared bucket bounds.
pub struct LabeledHistogram {
    name: &'static str,
    labels: &'static [&'static str],
    cells: Mutex<BTreeMap<Vec<String>, Arc<HistogramCell>>>,
}

impl LabeledHistogram {
    #[must_use]
    pub const fn new(name: &'static str, labels: &'static [&'static str]) -> Self {
        Self { name, labels, cells: Mutex::new(BTreeMap::new()) }
    }

    /// Numeric upper bounds parsed from the registry descriptor (string form).
    fn bounds(&self) -> Vec<f64> {
        descriptor_for(self.name)
            .map(|descriptor| {
                descriptor
                    .buckets
                    .iter()
                    .filter_map(|bound| bound.parse::<f64>().ok())
                    .collect()
            })
            .unwrap_or_default()
    }

    fn cell(&self, values: &[&str], bucket_len: usize) -> Option<Arc<HistogramCell>> {
        let key = key_for(self.labels, values)?;
        let mut cells = self.cells.lock().ok()?;
        Some(Arc::clone(cells.entry(key).or_insert_with(|| {
            let mut bucket_counts = Vec::with_capacity(bucket_len + 1);
            for _ in 0..bucket_len + 1 {
                bucket_counts.push(AtomicU64::new(0));
            }
            Arc::new(HistogramCell {
                bucket_counts,
                sum_millis: AtomicU64::new(0),
                count: AtomicU64::new(0),
            })
        })))
    }

    pub fn observe(&self, values: &[&str], seconds: f64) {
        let bounds = self.bounds();
        let Some(cell) = self.cell(values, bounds.len()) else { return };
        for (index, bound) in bounds.iter().enumerate() {
            if seconds <= *bound {
                if let Some(bucket) = cell.bucket_counts.get(index) {
                    bucket.fetch_add(1, Ordering::Relaxed);
                }
            }
        }
        // The +Inf bucket always counts.
        if let Some(inf) = cell.bucket_counts.last() {
            inf.fetch_add(1, Ordering::Relaxed);
        }
        cell.sum_millis
            .fetch_add((seconds * 1000.0).round().max(0.0) as u64, Ordering::Relaxed);
        cell.count.fetch_add(1, Ordering::Relaxed);
    }

    pub fn preregister(&self, values: &[&str]) {
        let bounds = self.bounds();
        let _ = self.cell(values, bounds.len());
    }

    pub fn render(&self, out: &mut String) {
        render_header(out, self.name, "histogram");
        let bounds = self.bounds();
        let Ok(cells) = self.cells.lock() else { return };
        for (values, cell) in cells.iter() {
            let base = render_label_set(self.labels, values);
            let inner = base.trim_start_matches('{').trim_end_matches('}');
            let separator = if inner.is_empty() { "" } else { "," };
            for (index, bound) in bounds.iter().enumerate() {
                let value = cell
                    .bucket_counts
                    .get(index)
                    .map(|counter| counter.load(Ordering::Relaxed))
                    .unwrap_or(0);
                out.push_str(&format!(
                    "{}_bucket{{{inner}{separator}le=\"{bound}\"}} {value}\n",
                    self.name
                ));
            }
            let inf = cell
                .bucket_counts
                .last()
                .map(|counter| counter.load(Ordering::Relaxed))
                .unwrap_or(0);
            out.push_str(&format!(
                "{}_bucket{{{inner}{separator}le=\"+Inf\"}} {inf}\n",
                self.name
            ));
            let sum = cell.sum_millis.load(Ordering::Relaxed) as f64 / 1000.0;
            out.push_str(&format!("{}_sum{base} {sum}\n", self.name));
            out.push_str(&format!(
                "{}_count{base} {}\n",
                self.name,
                cell.count.load(Ordering::Relaxed)
            ));
        }
    }
}
```

```rust
    /// of (prepared, appended, spans). Generation is pure (no store append), so
    /// doing it under the queue lock is safe.
    fn prepare_front(
        &self,
    ) -> Result<Option<(Vec<CanonicalChioReceipt>, usize, usize)>, OTelReceiptExportError> {
        let mut queue = self
            .queue
            .lock()
            .map_err(|_| OTelReceiptExportError::Queue("OTEL queue mutex poisoned".to_string()))?;
        let Some(item) = queue.front_mut() else { return Ok(None) };
        if item.prepared.is_none() {
            item.prepared = Some(self.sink.prepare_receipts(&item.export)?);
        }
        let prepared = item.prepared.clone().unwrap_or_default();
        Ok(Some((prepared, item.appended, item.spans)))
    }

        let mut queue = self
            .queue
            .lock()
            .map_err(|_| OTelReceiptExportError::Queue("OTEL queue mutex poisoned".to_string()))?;
        if let Some(item) = queue.front_mut() {
            item.appended = appended;

    fn drain_locked(&self) -> Result<ReceiptStoreSinkSummary, OTelReceiptExportError> {
        let mut summary = ReceiptStoreSinkSummary::default();
        for _ in 0..self.config.drain_limit {
            let Some((prepared, already, spans)) = self.prepare_front()? else {
                break;
            };
            let mut appended = already;
            let append_result = self.sink.append_from(&prepared, &mut appended);
            let newly = appended.saturating_sub(already);
            if newly > 0 {
                self.record_appended(newly)?; // span-granular
            }
            match append_result {
                Ok(()) => {
                    let _ = self.pop_front()?;
                    summary.accepted_spans += spans;
                    summary.appended_receipts += spans;
                }
                Err(error) => {

                    if remaining > 0 {
                        self.record_append_error(remaining)?; // span-granular

                    if error.is_retryable_batch_error() {

                        // with the SAME ids.
                        self.set_front_appended(appended)?;
                    } else {
                        let _ = self.pop_front()?;
                    }
                    return Err(error);
                }
            }
```

  ```rust
                          self.metrics.record_export(&exporter_name, crate::metrics_sink::ExportOutcome::Ok);
                      }
                      // Lag: persistence-to-ack for the newest event in the batch.
                      let now = SystemTime::now().duration_since(UNIX_EPOCH).map(|d| d.as_secs()).unwrap_or(0);
                      if let Some(persisted) = events.iter().map(|e| e.persisted_unix_secs()).max() {
                          self.metrics.observe_export_lag(&exporter_name, "info", now.saturating_sub(persisted) as f64);
                      }
                      self.acked.insert(exporter_name.clone(), max_seq);
                      if let Some(store) = &self.cursor_store {
                          store.set_acked(&exporter_name, max_seq)?;
                      }
                  }
                  Err(e) => {
                      let now = SystemTime::now().duration_since(UNIX_EPOCH).map(|d| d.as_secs()).unwrap_or(0);
                      for event in &events {
                          self.metrics.record_export(&exporter_name, crate::metrics_sink::ExportOutcome::Dlq);
                          let event_json = serde_json::to_string(event).unwrap_or_else(|_| {
                              format!("{{\"serialize_error\": \"receipt {}\"}}", event.receipt.id)
                          });
                          self.dlq.push(FailedEvent {
                              event_json,
                              error: e.to_string(),
                              failed_at: now,
                              exporter_name: exporter_name.clone(),
                          });
                      }
                      // acked_seq for this exporter is NOT advanced: the range is
                      // redelivered next poll (at-least-once). Idempotent ingest
                      // (ADR-0009) dedups downstream.
                  }
              }
              self.metrics.set_dlq_depth(&exporter_name, self.dlq.len() as u64);
          }

          // Read cursor resumes at the slowest exporter so nothing is skipped.
          self.cursor = self.acked.values().copied().min().unwrap_or(max_seq);
          Ok(())
  ```

```rust
pub fn record_receipt_health_gauges(

    now_unix_ms: u64,

        .unwrap_or(0);
    chio_metrics_spec::runtime::families::RECEIPT_CHECKPOINT_AGE_SECONDS.set(&[], age_seconds);
}
```

## Codex round-3 findings resolution (PR #968)

Seven review findings addressed; each behavioral fix carries a test. Theme: instruments must not lie, must not false-page, must not explode cardinality.

1. Finding 6 (P1, chio-http-core authority.rs) - do not page on normal HTTP denies. A policy/capability deny is an expected fail-closed decision, so it no longer increments `chio_dispatch_failure_total{outcome="denied"}` (which feeds the P0 `ChioDispatchFailure` alert). The deny branch now records only the guard-verdict metrics; only a genuine evaluation error (`outcome="error"`) feeds the paging counter. The `"denied"` outcome is removed from `preregister_known_label_sets` and no code produces it. Tests: `policy_deny_is_not_recorded_as_a_dispatch_failure` (authority), `dispatch_failure_records_error_never_deny_or_allow` (metrics), `preregister_known_label_sets_seeds_fail_open_and_dispatch` updated.
2. Finding 7 (P2, chio-wasm-guards guard.rs) - bounded deny reason classes. `chio_guard_deny_total{reason_class}` no longer carries the enforcement mode (`blocking`/`advisory`) or a raw free-form reason. A new `classify_deny_reason_class(Option<&str>)` maps the guard-provided reason to a closed enum (`policy`, `pii`, `secret`, `prompt_injection`, `oversize`, `fuel`, `trap`, `malformed`, `other`); a novel reason collapses to `other`. `REASON_CLASS_LABEL_VALUES` extended (malformed/other) and its lock test updated. Tests: `classify_*` unit tests, `deny_records_bounded_reason_class_from_reason_string`.
3. Finding 1 (P2, chio-wasm-guards guard.rs) - documented reload outcome. `record_reload_seq` (the successful apply path) now increments `chio_guard_reload_total` under the documented `applied` outcome instead of an undeclared `ok` series. Test: `record_reload_seq_uses_documented_applied_outcome`.

5. Finding 3 (P2, chio-otel-receipt-exporter ingress.rs) - count only newly appended receipts after retry.
