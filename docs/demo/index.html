This is an interactive demonstration. It runs the @chio-protocol/browser verify path against a bundled sample receipt entirely in your browser, and is not a substitute for an audited release of the SDK.

Chio receipt verify (browser)

Loads a public-key-only signed receipt from tests/bindings/vectors/receipt/v1.json and verifies it against the embedded kernel key. Verify runs entirely in this tab; no server round trip.
