This is an interactive demonstration of the @chio-protocol/passkey browser-to-issuer flow: a passkey assertion is presented to a Chio issuer that mints an audience-pinned PasskeyCapability. The browser holds zero key material and never signs anything, and this demo is not a substitute for an audited release of the SDK.

Chio passkey custody (browser)

Calls navigator.credentials.get for an issuer-bound challenge, POSTs the assertion to the issuer, and renders the minted PasskeyCapability. Then revokes the credential at the issuer test-double and replays the kernel call to show the revocation cascade through the revocation oracle.
